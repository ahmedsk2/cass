# CASS — Conference Abstract Submission System

A multi-tenant platform for conference organizers to collect abstracts, run peer review, and announce decisions. Each conference gets a public submission page with a QR code and short link.

Status: v2 rebuild in progress. Design: `docs/superpowers/specs/2026-09-10-cass-v2-design.md`.

Stack: PHP 8.4, Laravel 13, Filament 5, Livewire 4, Tailwind 4, MySQL 8, Pest 5. Deployed with Docker on Oracle Cloud via Coolify.
