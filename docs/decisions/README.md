# Decisions

One short file per decision, numbered in the order made: `NNNN-short-slug.md`. Each one says, in a paragraph or a few bullets:

- **Context**: what forced a choice.
- **Decision**: what was chosen and by whom (the owner, or the engineering default the owner accepted), with the date.
- **Consequence**: what that costs or rules out.
- **To reverse**: the one-line change that would undo it, and the test to invert.

A decision is never edited to say something else; a later file supersedes it and names the one it replaces. `docs/superpowers/plans/backlog.md` keeps what is deferred; this folder keeps what is decided.

0001 to 0009 are the owner's launch decisions of 2026-10-01, copied unedited from the backlog, so they keep the backlog's wording rather than the headings above.
